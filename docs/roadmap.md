# Roadmap after the MVP baseline

## 1. Detection breadth

- Add test-backed Chrome tab-click coaching.
- Cover browser toolbar and common non-menu controls.
- Define an application-specific detector adapter seam.
- Build a living supported-action matrix.

## 2. Notification acceptance

- Review every presentation mode individually.
- Define compatible and conflicting channel combinations.
- Verify native banner authorization.
- Capture Dock badge and attention behavior.
- Add Reduce Motion and multi-display acceptance.

## 3. Product identity

- Decide whether Shortcut Coach is the final name.
- Create original iconography, menu-bar symbol, colors, copy, and sound.

## 4. Distribution

- Onboarding and permission recovery.
- Launch-at-login.
- Developer ID archive and notarization.
- Update strategy.
- Release privacy policy and licensing decision.

## 5. Quality

- UI automation for settings and history.
- Persistence migration tests.
- Crash and recovery diagnostics.
- Performance and memory profiling.
