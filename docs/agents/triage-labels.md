# Triage labels

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `in-progress` | `in-progress` | Active work has an assigned owner and linked branch or pull request |
| `ready-for-human` | `ready-for-human` | Requires human implementation or a decision |
| `wontfix` | `wontfix` | Will not be actioned |

Use exactly one canonical triage label on every open issue. An `in-progress` issue must be assigned and must link to its active branch or pull request. Remove `in-progress` when work stops, merges, or becomes blocked.
