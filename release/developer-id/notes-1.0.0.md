# Shortcut Coach 1.0.0 pre-release

Shortcut Coach watches supported mouse-driven macOS actions and teaches the equivalent keyboard shortcut. This pre-release includes the full cross-app coaching detector, notification presentation choices, menu-bar inbox, history, and settings.

## Install

1. Download `Shortcut-Coach-1.0.0.dmg`.
2. Open it and drag **Shortcut Coach** to **Applications**.
3. Launch the app and grant Accessibility access when macOS asks. Accessibility access is required for the full coaching detector.

Requires macOS 14 or later. The app is universal for Apple silicon and Intel Macs, signed with Developer ID, notarized by Apple, and distributed with a stapled notarization ticket.

This is a pre-release build intended for testing. Please report defects in this repository's issue tracker.
