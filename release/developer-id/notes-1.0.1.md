# Shortcut Coach 1.0.1 pre-release

This patch release strengthens Shortcut Coach's permission recovery, manual-action verification, and notification presentation behavior.

## Highlights

- Shows separate, truthful Accessibility and Input Monitoring permission states.
- Verifies Chrome tab and Settings actions before coaching.
- Fails closed for ambiguous Finder Trash and macOS window-control actions.
- Improves multi-display presentation placement, Reduce Motion behavior, channel conflicts, dismissal, and OS-channel diagnostics.

## Install

1. Download `Shortcut-Coach-1.0.1.dmg`.
2. Open it and drag **Shortcut Coach** to **Applications**.
3. Launch the app and grant both Accessibility and Input Monitoring when macOS asks.

Requires macOS 14 or later. The app is universal for Apple silicon and Intel Macs, signed with Developer ID, notarized by Apple, and distributed with a stapled notarization ticket.

This is a pre-release build intended for testing. Please report defects in this repository's issue tracker.
